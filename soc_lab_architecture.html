AI Automation Pipeline — Shuffle SOAR + Ollama LLM
All AI processing is local (Ollama/Llama3 on 172.16.10.90). No data leaves the lab network. Internet access only needed for initial model download.
1

Alert Generated — ELK / Elasticsearch

Elastic Security detection rule fires. Alert contains: source IP, hostname, process hash, event ID, timestamp, severity.

POST http://172.16.10.10:9200/_watcher/watch

▼
2

Shuffle SOAR — Webhook Trigger

Elasticsearch webhook fires → Shuffle receives alert payload → workflow starts automatically.

POST http://172.16.10.90:3001/api/v1/hooks/...

▼
3

Data Extraction — Shuffle Action

Shuffle extracts fields: src_ip, process.hash.sha256, winlog.event_id, host.name, rule.name.

▼
4

Ollama LLM Triage (local, private)

Shuffle calls Ollama API with alert context. Llama3 model generates: natural-language summary, severity score (1-10), recommended action, MITRE technique guess.

POST http://172.16.10.90:11434/api/generate

▼
5

OpenCTI IOC Check

Query OpenCTI for known indicators (IP, hash, domain). Returns threat intel context, threat actor attribution if known.

GraphQL → http://172.16.10.80:8080/graphql

▼
6

Cortex Automated Analysis

Cortex runs analyzers: VirusTotal hash lookup, IP reputation (abuse.ch), URL analysis. Results enriched into case.

POST http://172.16.10.20:9001/api/analyzer/.../run

▼
7

TheHive Case Creation

Shuffle creates enriched case in TheHive 5 with: AI summary, IOC data, Cortex results, observables, MITRE tags, severity. Case assigned to analyst.

POST http://172.16.10.20:9000/api/v1/case

▼
8

Velociraptor Hunt Trigger

If severity ≥ 7: Shuffle triggers Velociraptor hunt on affected endpoint. Collects process list, network connections, recent files, memory artifacts.

POST http://172.16.10.50:8000/api/v1/CreateHunt

▼
9

Analyst Review — TheHive Dashboard

Analyst receives fully enriched case. One-click access to: AI summary, threat intel, Cortex reports, Velociraptor artifacts. MTTR drastically reduced.

http://172.16.10.20:9000 — TheHive UI

AI/SOAR VM — Software Stack
Shuffle SOAR — Open Source (172.16.10.90:3001)
  • Deployment: Docker Compose
  • Function: Visual workflow automation
  • Integrations: ELK, TheHive, Cortex, OpenCTI, Velociraptor, Ollama
  • Triggers: Webhooks, Cron, Manual
  • Port: 3001 (HTTP)
Ollama — Local LLM Server (172.16.10.90:11434)
  • Model: llama3:8b (recommended) or mistral:7b
  • RAM: ~8 GB for model + ~6 GB OS/Shuffle = 16 GB total
  • GPU: CPU-only mode (no GPU pass-through needed)
  • API: REST — compatible with OpenAI format
  • Privacy: 100% local, zero data exfiltration
  • Use cases: Alert triage, report drafting, IOC explanation
TheHive 5 + Cortex (172.16.10.20)
  • TheHive port: 9000 (HTTP)
  • Cortex port: 9001 (HTTP)
  • Cortex analyzers: VirusTotal, abuse.ch, Shodan, URLhaus, MalwareBazaar
  • Case template: Auto-populated by Shuffle workflow
  • Responders: Firewall block, email notification (optional)
OpenCTI Platform (172.16.10.80:8080)
  • Threat feeds: MITRE ATT&CK, OpenCTI dataset, manual IOC import
  • ATT&CK Navigator: container on same VM, port 4242
  • API: GraphQL (authenticated)
  • Export: STIX 2.1, CSV, JSON
